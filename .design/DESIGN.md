# 线上咖啡店 — 视觉系统

## 风格

温馨手作 + 编辑风。像一本纸质咖啡菜单被数字化，有温度、有留白、有细节。

## 色彩

```css
--cream: #faf8f3;        /* 主背景，米白色 */
--paper: #ffffff;        /* 卡片背景 */
--ink: #2c241b;          /* 主文字，深咖啡 */
--ink-light: #6b5d4d;    /* 次要文字 */
--coffee: #6f4e37;       /* 咖啡棕 */
--coffee-light: #a67c52; /* 浅咖啡 */
--terracotta: #c4705a;   /* 陶土红点缀 */
--leaf: #5a7a5a;         /* 绿叶点缀 */
--gold: #c9a227;         /* 小面积金色 */
```

## 字体

- 标题：Playfair Display（衬线，优雅）
- 正文：Plus Jakarta Sans（无衬线，清晰）
- 标签/价格：DM Mono（等宽，菜单感）

## 组件规范

### 按钮
- Primary：咖啡棕底 + 奶油色字，圆角 8px
- Secondary：奶油色底 + 咖啡棕边框
- Ghost：透明底，悬停下划线

### 卡片
- 白色底、细阴影、圆角 12px
- 图片 4:3，hover 轻微放大

### 导航
- 顶部固定，logo 在左，链接在右，购物车带数量徽章

### 输入框
- 浅米色边框，focus 咖啡棕边框

## 页面布局

- 最大宽度 1280px，居中
-  generous padding（py-20 px-6）
- 网格：商品 3 列桌面 / 2 列平板 / 1 列手机

## 动效

- 页面加载：内容淡入上滑
- 商品卡片：hover 上浮 + 阴影加深
- 购物车：添加商品时徽章跳动
- 页面切换：简单淡入淡出
